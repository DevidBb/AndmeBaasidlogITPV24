# Tarkov Map — карта на телефоне, позиция по скриншоту

Делаешь скрин в рейде (PrtSc) → на телефоне открывается карта с твоей точкой и направлением взгляда.

## Как это работает
EFT пишет координаты в имя файла скриншота
(`...]_-113.6, 2.5, 84.1_0.0, -0.9, 0.0, 0.4_...png`). `server.py` на ПК следит за папкой
скриншотов и сразу отправляет позицию на телефон. Карты (SVG/тайлы) и их калибровка берутся с
[tarkov.dev](https://tarkov.dev) (open-source).

## Запуск
1. Установи Python 3 на ПК (галочка «Add to PATH»).
2. Запусти `start.bat` (или `python server.py`). Он напишет адрес вида `http://192.168.1.10:8080`.
3. Телефон в той же Wi-Fi сети → открой этот адрес в Chrome/Safari →
   «Добавить на главный экран» — будет как приложение.
4. Windows может спросить про брандмауэр — разреши для частной сети.

Карта выбирается автоматически из логов игры (если найдены в `C:\Battlestate Games\EFT\Logs`),
иначе выбери её вверху вручную. Этаж на многоуровневых картах переключается по высоте.

## Параметры
- `--screens ПУТЬ` — папка скриншотов (по умолчанию `Документы\Escape from Tarkov\Screenshots`)
- `--logs ПУТЬ` — папка логов игры для автоопределения карты
- `--port 8080` — порт
- `--delete` — удалять скриншоты после чтения, чтобы не копились

Кнопка ◎ — следовать за меткой (выключается, если двигаешь карту пальцем).
